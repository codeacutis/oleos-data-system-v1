# Oleos Data System

## Objetivo

Produção de um Dashboard de visualização de dados para um estudo de Aromaterapia em Crianças com TEA.

## Problema

A produção de dados gerados pelo estudo estava sendo anotado à mão pelos autores, gerando carga cognitiva excessiva para mapeamento dos indicadores e baixa qualidade de amostragem dos dados brutos gerados.

## Stack
Python, MySQL e Streamlit/Plotly Express
